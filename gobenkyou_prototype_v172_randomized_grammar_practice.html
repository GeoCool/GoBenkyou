Quick guide

How to use the practice

Each practice gives you a sentence in your native language. Your job is to break it down using GoBenkyou's position system.

  1. Think through the sentence. Assign each word its position in your mind.
  2. Recall the meanings. Think of each word’s meaning in your mind; you do not need to type answers.
  3. Reveal help when needed. Scroll down to see the full vertical breakdown, then use the bottom button to move on whenever you feel ready.

You can scroll up and down through the practice. Skip this guide to start right away.

GoBenkyou assistant · interactive demo

Chat about your language learning

Chat normally about the Library, grammar patterns, sentence positions, or vocabulary. Ask explicitly when you want a draft. This demo uses guided replies and is not yet connected to a live AI service.

This chat only discusses grammar patterns for the language currently selected. You can enter a pattern in its native writing system or romanized form (for example, Japanese によって or “ni yotte”). If a pattern is not found in the selected language, the reply will be exactly: “Grammar pattern not found.” To add a pattern, put its name in quotation marks (e.g. "ni yotte"). To request more than one pattern at once, put all the pattern names inside the same pair of quotation marks and separate them with a comma, for example: "ni yotte, aru men de wa". You can also ask how to use the Library or organize vocabulary.
